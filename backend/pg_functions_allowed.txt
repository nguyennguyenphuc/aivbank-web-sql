# Danh sach ham PostgreSQL duoc phep trong truy van hoc vien.
#
# ==========================================================================
# VI SAO LA DANH SACH CHO PHEP, KHONG PHAI DANH SACH CAM
# ==========================================================================
# Ban DuckDB suy ra tap ham an toan TU CHINH ENGINE (`duckdb_functions()`),
# roi cam them mot nhum nho. Lam duoc vi DuckDB co ~1.200 ham va gan nhu tat
# ca deu vo hai.
#
# `pg_proc` cua PostgreSQL 18 co ~3.300 dong, trong do hang tram ham doc file,
# do catalog, hoac doi trang thai may chu. Neu port nguyen xi - doi
# `duckdb_functions()` thanh `pg_proc` - thi nhanh fail-closed o
# `api/guard.py` (cho `exp.Anonymous`) se AM THAM tro thanh fail-open cho
# pg_read_file, pg_ls_dir, pg_sleep, to_regclass, pg_get_viewdef,
# has_table_privilege va moi ham pg_stat_get_*.
#
# Vi vay chieu suy luan bi DAO NGUOC: file nay la nguon, con `pg_proc` chi
# dung de KIEM CHUNG file nay (moi ten phai ton tai that; khong ten nao duoc
# trung voi danh sach cam). Ca hai phep kiem chay luc khoi dong va lam API
# KHONG khoi dong duoc neu that bai.
#
# Ba ly do danh sach cam khong du:
#   1. PostgreSQL 18.1 co the them ham moi - danh sach cam nhan het theo mac
#      dinh, danh sach cho phep tu choi het theo mac dinh.
#   2. Mot lenh `CREATE EXTENSION` cua nguoi van hanh tuong lai them ca cum
#      ham la - danh sach cam khong biet ten nao trong so do.
#   3. Sot mot ten trong danh sach cam la mot lo hong; sot mot ten trong danh
#      sach cho phep chi la mot hoc vien phai hoi giang vien.
#
# Them ten vao day la MO RONG be mat tan cong. Chi them khi co nhu cau day hoc
# that, va kiem lai ham do khong doc file, khong do catalog, khong doi trang
# thai.
# ==========================================================================
